# 🚚 Tradifoot — Programme de Livraison (Delivery Schedule Calendar)

Interface web interactive pour la visualisation et le suivi des **Programmes de Livraison** de Tradifoot.

---

## 🌟 Fonctionnalités

* **Calendrier Mensuel Interactif :**
  * Grille mensuelle dynamique (vue par défaut sur le mois en cours).
  * Indicateurs visuels par couleur selon le statut logistique (Vert = Livré, Ambre = En Transit, Indigo = Programmé).
  * Badges journaliers affichant le nombre de tournées et le volume total expédié.
* **Manifeste Quotidien Réactif :**
  * Mise à jour instantanée des tournées lors du clic sur n'importe quel jour du calendrier.
  * Cartes de livraison stylisées : Chauffeur, Véhicule / Matricule, Magasin / Dépôt destinataire, Wilaya, Quantité et Colis.
  * Filtrage instantané par statut (*Tous*, *En Transit*, *Livrés*, *Prévus*).
  * Inspecteur modal avec instructions de déchargement et horaires.
* **Design Moderne SaaS :**
  * Thème sombre épuré (`bg-slate-950`) avec panneaux glassmorphiques.
  * Entièrement responsive (Desktop 2 panneaux & Mobile).
  * Construit en Vanilla JavaScript, Tailwind CSS (CDN) et FontAwesome.

---

## 🚀 Utilisation Locale

Ouvrez simplement le fichier `index.html` dans n'importe quel navigateur web moderne.

## 🌐 Déploiement GitHub Pages

Ce projet peut être hébergé gratuitement en 1 clic via GitHub Pages :
1. Rendez-vous sur votre dépôt : `https://github.com/Neronero369/Delivery-Moh`
2. Allez dans **Settings** > **Pages**
3. Sous **Source**, sélectionnez la branche `main` et le dossier `/ (root)`
4. Cliquez sur **Save**
